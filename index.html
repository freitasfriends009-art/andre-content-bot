Andre Content Bot

Sobre o aplicativo

O Andre Content Bot é uma ferramenta para auxiliar usuários a enviar e gerenciar vídeos para publicação em suas próprias contas do TikTok.

Como funciona

O usuário conecta sua própria conta TikTok e seleciona os vídeos que deseja enviar. O aplicativo utiliza as ferramentas oficiais disponibilizadas pelo TikTok para realizar a integração.

Privacidade

O aplicativo utiliza apenas as informações necessárias para realizar a integração autorizada pelo usuário.
